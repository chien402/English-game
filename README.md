# Word Quest｜星星郵差的謎語

一款溫暖可愛的英文單字童話冒險。跟著見習探險家艾登和小狐狸露露，解開謎語、尋找森林裡的小星星，並在任務中練習大考中心 Level 4 單字。

## 開始遊玩

直接用瀏覽器開啟 `index.html` 即可遊玩，無需安裝套件或建置工具。

## 發布到 GitHub Pages

此專案包含 `.github/workflows/deploy-pages.yml`。將專案推送到 GitHub 的 `main` 分支後，GitHub Actions 會自動把根目錄的靜態網站發布到 GitHub Pages。

第一次發布前，請在 GitHub 專案的 **Settings → Pages → Build and deployment** 將來源設成 **GitHub Actions**。發布完成後，網址格式為：

`https://<帳號>.github.io/<專案名稱>/`

也可以在 Actions 頁面手動執行 `Deploy to GitHub Pages`。

## 本章單字

本章以大考中心《高中英文參考詞彙表（111 學年度起適用）》第四級候選詞編寫：`messenger`、`mysterious`、`riddle`、`shelter`、`rescue`、`reward`。

參考：[大考中心高中英文參考詞彙表](https://www.ceec.edu.tw/files/file_pool/1/0N118345621497981164/%E9%AB%98%E4%B8%AD%E8%8B%B1%E6%96%87%E5%8F%83%E8%80%83%E8%A9%9E%E5%BD%99%E8%A1%A8%28111%E5%AD%B8%E5%B9%B4%E5%BA%A6%E8%B5%B7%E9%81%A9%E7%94%A8%29.pdf)
